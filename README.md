# Mecánica de Suelos II-Unab

Libro-tutor del curso **Mecánica de Suelos II** de Ingeniería Civil, Universidad Nacional de Barranca (ciclo 2026-2).

**Abrir el libro:** https://alex1525-cloud.github.io/mecanica-suelos/

Se lee bien en el celular y tiene modo claro, oscuro y automático.

## Contenido

| Grupo | Temas |
|---|---|
| Fundamentos | Relaciones gravimétricas (con buscador "necesito / tengo"), clasificación SUCS y AASHTO |
| Transmisión de esfuerzos | Esfuerzos geostáticos, Boussinesq, método 2:1, bulbo de presiones, carta de Newmark |
| Consolidación | Ensayo edométrico, asentamientos, velocidad de consolidación, métodos gráficos (Casagrande, Pacheco Silva, Butterfield, Taylor) |
| Resistencia y aplicaciones | Resistencia al corte, capacidad portante, estabilidad de taludes |
| Libro de Budhu · Cap. 16 | Teoría de estabilidad de taludes y los ejemplos 16.1 a 16.8 resueltos dovela por dovela |
| Práctica para el parcial | Problemas 1, 2 y 3 del examen, resueltos paso a paso |
| Material resuelto | Ejercicios resueltos y formulario |

Cada tema trae la teoría, las fórmulas con su origen y sus límites, los procedimientos gráficos paso a paso y una calculadora.

## Bibliografía

- Budhu, M. *Soil Mechanics and Foundations*, 3.ª ed. Wiley.
- Terzaghi, K., Peck, R. y Mesri, G. *Soil Mechanics in Engineering Practice*, 3.ª ed. Wiley.
- Apuntes de las clases del curso.
